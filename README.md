# Jarvis AI Assistant

Это проект ИИ-ассистента «Джарвис» для Windows 11. Он может слушать ваш микрофон в фоновом режиме, общаться с вами голосом и выполнять системные команды, такие как запуск программ, смена аккаунта Steam и нажатие горячих клавиш.

Проект готов к автоматической сборке через GitHub Actions. Вам не нужно устанавливать локальный компилятор!

## Требования
* Аккаунт на GitHub.
* Токен от OpenAI API (или другого LLM провайдера, совместимого с форматом OpenAI).

## Как собрать и запустить проект

1. **Создайте репозиторий на GitHub**
   - Зайдите на [github.com](https://github.com/) и создайте новый пустой репозиторий (без README, без .gitignore).

2. **Загрузите код в репозиторий**
   - Склонируйте репозиторий к себе на компьютер или загрузите файлы вручную.
   - Если загружаете вручную через браузер:
     - Нажмите "Add file" -> "Upload files".
     - Перетащите все файлы из этой папки (включая папку `src`, `include`, файл `CMakeLists.txt` и папку `.github`). **Внимание**: чтобы загрузить скрытую папку `.github`, возможно, вам придется создать её прямо на GitHub или воспользоваться Git через командную строку:
       ```bash
       git init
       git add .
       git commit -m "Initial commit"
       git branch -M main
       git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
       git push -u origin main
       ```

3. **Автоматическая сборка в GitHub Actions**
   - Как только вы запушите код в ветку `main`, GitHub автоматически начнет процесс сборки (благодаря файлу `.github/workflows/build.yml`).
   - Перейдите во вкладку **Actions** в вашем репозитории.
   - Вы увидите запущенный процесс "Build Jarvis". Дождитесь его завершения (появится зелёная галочка).
   - Нажмите на успешный запуск. В самом низу страницы в разделе **Artifacts** вы найдете архив `Jarvis-Windows`.
   - Скачайте этот ZIP-архив к себе на компьютер.

4. **Настройка Jarvis**
   - Распакуйте скачанный архив. Внутри будут файлы `Jarvis.exe` и `config.json`.
   - Откройте файл `config.json` в любом текстовом редакторе.
   - Вставьте ваш API-ключ в поле `api_key`.
   - Настройте пути к приложениям в разделе `apps` (убедитесь, что используете двойные обратные слеши `\\` для путей в Windows).
   - Укажите ваши логины и пароли в разделе `steam_accounts`.

5. **Запуск**
   - Просто запустите `Jarvis.exe` двойным кликом.
   - Программа откроет консоль и напишет "Jarvis is now listening...". Скажите что-нибудь в микрофон!

## Архитектура
* **AudioControl**: Использует Windows SAPI (`ISpVoice` и `ISpRecognizer`) для синтеза и распознавания речи в фоновом потоке.
* **LLMController**: Отправляет запросы к LLM через `libcurl`. Ожидает либо текстовый ответ, либо JSON-команду (Function Calling).
* **SystemActions**: Управляет Windows: запускает приложения, меняет аккаунты Steam, эмулирует нажатия клавиш.
* **ConfigManager**: Загружает конфигурацию из `config.json` с помощью `nlohmann/json`.

## Примечания
- Для использования SAPI на русском языке убедитесь, что в настройках Windows установлен и выбран русский голосовой пакет.
- Программа использует системные микрофон и динамики по умолчанию.
